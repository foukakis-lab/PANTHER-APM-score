# Controlled data notice

This code distribution must not contain participant data, sample-level results, expression matrices, sequencing files, clinical spreadsheets, or private path configuration.

Sample and patient identifiers are pseudonymized but remain controlled research data. Technical-QC decisions, exclusion reasons, subtype calls, and subtype probabilities are also sample-level research outputs and must remain in approved storage unless a separate disclosure review authorizes release.

The public code accepts local paths at execution time. Keep local configuration and every generated result outside version control.
