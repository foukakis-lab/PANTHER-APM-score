# PANTHER-APM-score

Analysis code for the PANTHER translational study of an antigen processing
and presentation machinery (APM) score and differential benefit from
adjuvant dose-dense chemotherapy in high-risk early breast cancer.

## Available code

The [RNA-seq QC and SSPBC intrinsic subtyping module](workflows/rnaseq_qc_and_subtyping/README.md)
contains technical QC, expression-level QC, and SSPBC intrinsic subtyping.

APM-score development, validation, and downstream statistical analysis
code are not yet included.

## Documentation and citation

Execution instructions, software-environment requirements, contributor
information, and citation guidance are provided within each component.
See the [component contribution records](CONTRIBUTORS.md).

Study-level analysis documentation and publication citation metadata
will be completed alongside the remaining study code.
